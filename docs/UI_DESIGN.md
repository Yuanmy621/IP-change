# Linear 风格界面

此开发版以用户选择的 Linear 主题为方向，参考 Linear 官方设计说明，采用中性灰阶、柔和边界和有限的紫色强调。配色是本项目的实现，不是从 Codex 私有界面提取的精确主题。

## 组件选型与调研

| 参考 | 用途 | 选择原因 |
| --- | --- | --- |
| [Linear 官方设计说明](https://linear.app/now/behind-the-latest-design-refresh) | 灰阶、内容优先、侧栏退后、紧凑工具栏 | 主任务是地图选点，导航和辅助信息保持低对比 |
| [Web Awesome](https://github.com/shoelace-style/webawesome) · 3.14.0 | Dialog、Drawer、Details | 原生 Web Components 可嵌入现有 Go 静态页与 Android WebView，保留焦点管理与键盘关闭 |
| [Lucide](https://github.com/lucide-icons/lucide) · 1.55.0 | 导航、地图工具、状态与操作图标 | 统一线性 SVG 图标，按需打包；内置组件图标也使用本地 Lucide SVG |
| [Leaflet](https://leafletjs.com/) · 1.9.4 | 地图与已有平滑缩放 | 保留已有地图行为，重新装配工具栏、选点反馈与地图操作控件 |

官方组件文档：[Dialog](https://webawesome.com/docs/components/dialog)、[Drawer](https://webawesome.com/docs/components/drawer)、[Details](https://webawesome.com/docs/components/details)。仅使用免费组件，不依赖 Pro 或外部字体服务。

组件与图标打包至 `web/vendor/`，UI 资源不依赖 CDN。地图瓦片和真实地名查询仍需网络。Web Awesome 使用 MIT 许可证，Lucide 使用 ISC 许可证；许可证与打包产物一起保留。没有引入 React 等额外运行框架。

## 窗口排版

- 桌面宽度超过 900px：196px 侧栏、主地图、304px 操作区；设备连接和目标位置分区，设置与指南使用弹窗，收藏使用右侧抽屉。短窗口优先保留应用与恢复操作，让附加选项滚动。
- 手机竖屏：导航收起，搜索置顶，地图占主要空间；坐标及应用／恢复操作位于底部面板。快捷位置和网络选项通过手柄展开，附加选项滚动，主操作留在面板内。设备授权设置移动到设置弹窗，收藏改为底部抽屉。
- 手机横屏：600–900px 宽且高度不超过 500px 时，地图和操作区并排，减少底部面板对地图的遮挡。
- 极短竖屏（如输入法打开）：工作区可以滚动，以便继续编辑坐标和操作。

两种运行模式共用同一套组件，但授权和运行说明区分 Mac / USB 与 Android 本机。移动设备卡片时复用同一个 DOM 节点，保留状态和事件。

## 交互

搜索支持坐标解析和地名结果列表；`⌘K` / `Ctrl+K` 聚焦搜索，方向键浏览结果，Escape 收起。收藏保留名称、坐标与独立删除入口，兼容旧坐标收藏。对用户数据使用文本节点，不插入 HTML。

弹窗与抽屉提供焦点管理和键盘关闭；控件提供可访问名称与焦点样式；手机主操作至少 44px 高。减少动态效果偏好继续传入地图缩放与组件样式。状态、禁用规则和定位恢复流程沿用原实现。

## 维护与验证

```sh
npm ci
npm run build:ui  # 更新组件入口后重建，产物需一并保存
npm test
npm run preview
```

预览服务只绑定 `127.0.0.1:18766`，使用模拟设备和进程内会话，地名搜索通过 Photon 联网查询，坐标在本地解析，不调用 ADB。手机原生桥接模式为 `/?mode=phone`。预览用于验证 UI，不证明 Android 模拟定位能力。

本次浏览器验证覆盖：1448×772 桌面、320×568 和 390×844 手机竖屏、844×390 横屏；主题切换、地名／坐标搜索、收藏新增删除与选定、授权设置／指南组件、模拟应用与恢复。界面截图位于 `docs/images/`。真实设备验证须另行连接手机安装新版 APK。

修改普通 HTML / CSS / JS 无需重新打包组件，但需要重新构建 Mac 程序或 Android APK，才能更新嵌入资源。
